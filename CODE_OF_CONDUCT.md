# Code of Conduct

Be kind and be useful. This is a small project and we want people to feel comfortable asking questions,
reporting problems and sending patches.

- Be respectful. Disagree with ideas, not with people.
- No harassment, insults, or discrimination of any kind.
- Assume good faith, and say so when you are not sure what someone meant.
- Keep it on topic: the project, cars, and getting things working.

If someone breaks these rules, the maintainer may edit or remove comments, close threads, or block the person
from the repository. To report a problem, open a private security advisory on the repository
(Security tab, Report a vulnerability) or contact the maintainer, Durvank Deorukhkar, through his GitHub profile.
